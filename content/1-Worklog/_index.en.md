This worklog covers **twelve learning weeks** in the First Cloud AI Journey program at AWS Vietnam. It progresses from foundations to storage, data, authentication, monitoring and application-architecture analysis.

Each week includes objectives, daily activities, reflection and a point to clarify. Studying an additional service does not imply that it has been deployed in CloudDocs.

**Week 1:** [Learning about the internship organization and getting started with AWS](1.1-Week1/)

**Week 2:** [Studying AWS IAM and access management](1.2-Week2/)

**Week 3:** [Studying Amazon VPC and networking components](1.3-Week3/)

**Week 4:** [Studying Amazon EC2 and comparing it with Amazon Lightsail](1.4-Week4/)

**Week 5:** [Studying Amazon S3 and AWS storage options](1.5-Week5/)

**Week 6:** [Studying Amazon RDS and comparing it with Amazon DynamoDB](1.6-Week6/)

**Week 7:** [Studying AWS CLI, AWS CloudShell and IAM role usage](1.7-Week7/)

**Week 8:** [Studying Amazon Cognito, user authentication and token-based access control](1.8-Week8/)

**Week 9:** [Studying Amazon CloudWatch and system monitoring](1.9-Week9/)

**Week 10:** [Studying AWS Lambda and resource management with AWS Systems Manager](1.10-Week10/)

**Week 11:** [Studying Elastic Load Balancing, EC2 Auto Scaling and multi-AZ application deployment](1.11-Week11/)

**Week 12:** [Consolidating knowledge, relating it to CloudDocs and completing the internship report](1.12-Week12/)
