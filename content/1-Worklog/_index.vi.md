Nhật ký ghi lại **12 tuần học tập** trong chương trình First Cloud AI Journey tại AWS Việt Nam. Lộ trình đi từ kiến thức nền tảng đến lưu trữ, dữ liệu, xác thực, giám sát và phân tích kiến trúc ứng dụng.

Mỗi tuần gồm mục tiêu, nội dung theo ngày, tổng kết và điểm cần làm rõ. Các dịch vụ được tìm hiểu mở rộng không đồng nghĩa đã được triển khai trong CloudDocs.

[Worklog tuần 1](1.1-Week1/) — Tìm hiểu đơn vị thực tập và làm quen với AWS

[Worklog tuần 2](1.2-Week2/) — Tìm hiểu AWS IAM và quản lý quyền truy cập

[Worklog tuần 3](1.3-Week3/) — Tìm hiểu Amazon VPC và các thành phần mạng

[Worklog tuần 4](1.4-Week4/) — Tìm hiểu Amazon EC2 và so sánh với Amazon Lightsail

[Worklog tuần 5](1.5-Week5/) — Tìm hiểu Amazon S3 và các hình thức lưu trữ trên AWS

[Worklog tuần 6](1.6-Week6/) — Tìm hiểu Amazon RDS và so sánh với Amazon DynamoDB

[Worklog tuần 7](1.7-Week7/) — Tìm hiểu AWS CLI, AWS CloudShell và sử dụng IAM Role

[Worklog tuần 8](1.8-Week8/) — Tìm hiểu Amazon Cognito, xác thực người dùng và kiểm soát truy cập bằng token

[Worklog tuần 9](1.9-Week9/) — Tìm hiểu Amazon CloudWatch và giám sát hệ thống

[Worklog tuần 10](1.10-Week10/) — Tìm hiểu AWS Lambda và quản lý tài nguyên bằng AWS Systems Manager

[Worklog tuần 11](1.11-Week11/) — Tìm hiểu Elastic Load Balancing, EC2 Auto Scaling và triển khai ứng dụng trên nhiều Availability Zone

[Worklog tuần 12](1.12-Week12/) — Tổng hợp kiến thức, liên hệ với dự án CloudDocs và hoàn thiện báo cáo thực tập
